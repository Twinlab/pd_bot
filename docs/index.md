# PD Bot

PD Bot помогает участникам небольшого Discord-сервера собираться в игры,
слушать музыку и смотреть общую статистику. Один экземпляр обслуживает один
сервер; проект рассчитан примерно на 30–40 участников.

## Участникам сервера

Начните с `/help`. Основные сценарии:

- `/profile` — статистика участника, игровые аккаунты и последние матчи.
- `/party` — сбор компании с приглашениями и подтверждением готовности.
- `/play` — музыка в голосовом канале с общей очередью.
- `/tyan` — дневная тянка; цитаты и другие развлечения доступны через `/help`.

Полные параметры, ограничения и административные команды —
в [справочнике](commands.md). Какие данные сохраняются и кому видны —
на странице [данных и приватности](data-and-privacy.md).

## Владельцам экземпляра

- [Начало работы](getting-started.md) — приложение Discord, разрешения, ключи,
  настройка каналов и первый запуск.
- [Эксплуатация](deployment.md) — обновления, резервное копирование,
  восстановление и проверка неполадок.

Настройки из репозитория нужно адаптировать под свой сервер. Доступность музыки,
игровой статистики и автопостов зависит от настроенных внешних сервисов.

## Разработчикам

- [Архитектура](architecture.md) — карта исходников, постоянное и временное
  состояние, фоновые задачи и жизненный цикл.
- [Разработка](style-guide.md) — локальное окружение, стиль, проверки и изменение
  документации.

Основа проекта — Python 3.13+, discord.py, SQLite с Tortoise ORM и Pydantic.
Музыку обслуживает отдельный Lavalink через Wavelink. Исходники и история
изменений находятся в [репозитории проекта](https://github.com/twinlab/pd_bot).
