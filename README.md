# PD Bot

Discord-бот для одного небольшого сервера: игровые профили, музыка, сбор компании
и статистика общения. Проект рассчитан примерно на 30–40 участников и работает
одним процессом с SQLite; поддержка нескольких серверов не предусмотрена.

## Возможности

- **Профили и матчи:** `/profile`, привязка Steam и FACEIT, карточки последних
  матчей Dota 2 и CS2.
- **Музыка:** поиск, очередь и управление воспроизведением через Lavalink.
- **Сбор компании:** `/party`, приглашения, основной состав, резерв и проверка готовности.
- **Активность:** игровое и голосовое время, счётчики сообщений, отчёты и wrapped.
- **Жизнь сервера:** кнопки ролей, уведомления Twitch, аниме-арты и топ реакций.
- **Развлечения:** дневная `/tyan`, цитаты, дуэли и другие небольшие команды.

## С чего начать

Участнику сервера достаточно `/help` и [справочника команд](docs/commands.md).
Для своего экземпляра нужны приложение Discord, Docker Compose, собственные ID
каналов и ключи выбранных интеграций. Пошаговая настройка и запуск —
в [начале работы](docs/getting-started.md).

Базовый Compose использует готовый образ проекта. Простая правка YAML рядом с ним
не меняет настройки внутри образа: инструкция содержит отдельную конфигурацию
для сборки и запуска своего экземпляра.

Бот сохраняет статистику участников, привязки аккаунтов и часть сообщений для
топа реакций; `/snipe` показывает последнее доступное удалённое сообщение канала.
Перед установкой прочитайте [описание данных и приватности](docs/data-and-privacy.md).

## Разработка

Нужен Python 3.13+. В активированном виртуальном окружении:

```bash
python -m pip install -e ".[dev]"
python -m ruff check .
python -m ruff format --check .
python -m pytest tests/test_cogs/test_music_cog.py
```

Тесты используют подмены Discord и внешних API. Запуск бота и боевые токены для
обычной разработки не требуются. Полный порядок проверок —
в [руководстве разработчика](docs/style-guide.md).
