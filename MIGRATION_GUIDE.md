# Инструкция по миграции и запуску обновленного бота

Этот документ описывает шаги, необходимые для перехода на новую версию бота, использующую Docker и Tortoise ORM.

## Предварительные требования

1.  **Docker**: Убедитесь, что на вашем сервере установлены Docker и Docker Compose.
    *   Проверка: `docker --version` и `docker-compose --version`.

## Шаг 1: Резервное копирование (ОБЯЗАТЕЛЬНО)

Перед запуском новой версии сохраните текущие данные.

1.  Остановите текущего бота (если запущен через systemd):
    ```bash
    systemctl --user stop discord-bot.service
    ```
    *(Или используйте вашу команду остановки)*

2.  Создайте бэкап базы данных и конфига:
    ```bash
    mkdir -p backups/pre_docker_migration
    cp data/bot_data.db backups/pre_docker_migration/
    cp config/bot_settings.yaml backups/pre_docker_migration/
    cp .env backups/pre_docker_migration/
    ```

## Шаг 2: Подготовка окружения

1.  Убедитесь, что файл `.env` существует и содержит актуальный токен бота.
    *   Если его нет, скопируйте из бэкапа или создайте заново на основе `.env.example`.

2.  Убедитесь, что файл `config/bot_settings.yaml` на месте.

## Шаг 3: Запуск через Docker

Теперь мы запустим бота в контейнере.

1.  Соберите и запустите контейнер:
    ```bash
    docker-compose up -d --build
    ```
    *   `-d`: Запуск в фоновом режиме (detached).
    *   `--build`: Принудительная пересборка образа (важно для первого раза).

2.  Проверьте логи, чтобы убедиться, что бот запустился без ошибок:
    ```bash
    docker-compose logs -f
    ```
    *   Вы должны увидеть сообщения об инициализации базы данных (Tortoise ORM) и успешном входе бота в Discord.
    *   Нажмите `Ctrl+C`, чтобы выйти из просмотра логов (бот продолжит работать).

## Шаг 4: Проверка функциональности

1.  Зайдите в Discord и проверьте основные команды (например, `/activity`, `/mystats`).
2.  Проверьте, что данные (статистика, привязки) на месте.
    *   *Примечание:* Бот использует тот же файл `data/bot_data.db`, поэтому все данные должны сохраниться.

## Управление ботом

### Обновление кода

Теперь обновлять бота можно двумя способами:

1.  **Через Discord (как раньше):**
    *   Напишите команду `/update`.
    *   Бот скачает обновления (`git pull`) и перезапустится.
    *   *Важно:* Это работает, так как папка с кодом "проброшена" внутрь контейнера.

2.  **Вручную на сервере:**
    ```bash
    git pull
    docker-compose restart bot
    ```

### Обновление зависимостей

Если в обновлении изменился файл `pyproject.toml` (добавились новые библиотеки), простого перезапуска недостаточно. Нужно пересобрать контейнер:

```bash
git pull
docker-compose up -d --build
```

### Просмотр логов

Логи пишутся в папку `logs/` на сервере, как и раньше.
Также можно смотреть вывод контейнера:
```bash
docker-compose logs -f --tail=100
```

### Остановка бота

```bash
docker-compose down
```

## Решение проблем

*   **Если бот не запускается:** Смотрите логи (`docker-compose logs`).
*   **Если база данных повреждена:** Восстановите файл `data/bot_data.db` из бэкапа, созданного на Шаге 1.
